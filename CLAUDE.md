This project implements ROADMAP.md, the single planning document — read it before any architectural change (protocol types, the Solver interface, error taxonomy, backend selection, packaging) and say which phase or section the change serves. Section 4.1 records where the shipped protocol knowingly diverges from the target; treat those as open, not as precedent. Backend is the APBS 3.4.1 binary, from conda-forge (what CI tests) or a system package manager, never vendored source and never built here — APBS is compiled, so no Python installer can supply it. Because that pin is no longer enforced by a lockfile, tests/test_corpus.py asserts the version and re-checks the Born energies; treat a corpus diff as a real result change, not a test to regenerate. The sashimi.protocol module is a stable contract that the native solver (debye, shipped in phase 8) now shares with APBS — don't leak APBS concepts above it. Env is uv-managed: uv.lock is the single source of truth for Python, and there is no second package manager. Work through the phases in order; each has an exit criterion.
